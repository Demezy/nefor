# Modules and File Inputs

Programs grow by moving definitions into modules. A file's module identity is
its path relative to a configured module root: `modules/labels.mag` is required
as `modules.labels`.

```lisp
(require "modules.labels")

(artifact {:title modules.labels.title})
```

Definitions remain namespaced. Imports are transitive, each module evaluates
once per compilation, and circular imports are rejected. If the same module
identity exists in more than one configured root, loading fails as ambiguous
instead of silently choosing one.

## Files are immutable compilation inputs

`read` captures raw text and `read-json` parses a JSON value:

```lisp
(let prompt (read "data/prompt.md"))
(let manifest (read-json "data/manifest.json"))
```

Modules, text files, and JSON files are all source inputs. The first read of a
resolved path adds its contents to the loaded program's immutable snapshot.
Later reads reuse that content. Loading the source tree again creates a new
snapshot and observes edits.
