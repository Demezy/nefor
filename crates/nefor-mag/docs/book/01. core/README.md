# Core MAG

MAG is a small, strictly typed, pure functional programming language. A program
evaluates an immutable source snapshot and returns one artifact.

Read the chapters in order:

1. [Pure Typed Data Manipulation Language](<01. Pure Typed Data Manipulation Language.md>)
2. [Artifacts](<02. Artifacts.md>)
3. [Types](<03. Types.md>)
4. [Functions and Composition](<04. Functions and Composition.md>)
5. [Modules and File Inputs](<05. Modules and File Inputs.md>)

For the complete language compressed into one commented source file, read
[MAG in Five Minutes](<00. MAG in Five Minutes.md>). Its format is inspired by
[Learn X in Y Minutes](https://learnxinyminutes.com/): one executable tour for
orientation before the chapters explain each idea in depth.
