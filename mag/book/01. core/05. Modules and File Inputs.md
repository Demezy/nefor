# Modules and File Inputs

Programs grow by moving definitions into modules. A file's module identity is
its path relative to a configured module root: `modules/labels.mag` is imported
as `modules.labels`.

```mag
import modules.labels.{}

type ImportedTitle {title: String}
artifact(ImportedTitle {title: modules.labels.title})
```

An import is a direct source-block declaration, not an expression that returns
a module object. It evaluates the module and makes its bindings available under
the qualified namespace. A module therefore does not need an `artifact`
expression: its direct `let` bindings and nominal type declarations are exports,
and any final expression value is ignored by the importer. Imported ADTs retain
their owner-qualified constructors, including generic and inline-record payloads.

The empty selector `{}` keeps every binding qualified. A selective import can
also introduce local aliases:

```mag
import modules.labels.{title, number_label as label}

type LabelExample {title: String, example: String}
artifact(LabelExample {title: title, example: label(4)})
```

Imports are transitive, each module evaluates once per compilation, and circular
imports are rejected. If the same module identity exists in more than one
configured root, loading fails as ambiguous instead of silently choosing one.

## Files are immutable compilation inputs

`read` captures raw text and `` `read_json` `` parses a JSON value:

```mag
let prompt = read("data/prompt.md")
let manifest = read_json("data/manifest.json")
let project_name = get(manifest, "project")
```

`` `read_json` `` yields the JSON document as ordinary record, list, or scalar
data. Its checked type is `JsonValue`; record fields can be traversed with
`get`, and the value can be returned directly in an artifact. It remains
`JsonValue` even when its JSON shape happens to match a nominal MAG type.

Modules, text files, and JSON files are all source inputs. The first read of a
resolved path adds its contents to the current compilation's immutable snapshot.
Later reads reuse that content. Compiling the source tree again creates a new
snapshot and observes edits.

[`04-modules-and-files.mag`](../../examples/04-modules-and-files.mag) program
