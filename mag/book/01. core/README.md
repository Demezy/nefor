# Core MAG

MAG is a small, strictly typed, pure functional programming language. A program
evaluates an immutable source snapshot and returns one artifact.

Read the chapters in order:

1. [MAG in Five Minutes](<00. MAG in Five Minutes.md>)
2. [Pure Typed Data Manipulation Language](<01. Pure Typed Data Manipulation Language.md>)
3. [Artifacts](<02. Artifacts.md>)
4. [Types](<03. Types.md>)
5. [Functions and Composition](<04. Functions and Composition.md>)
6. [Modules and File Inputs](<05. Modules and File Inputs.md>)

The first chapter compresses the complete language into one commented source
file. Its format is inspired by
[Learn X in Y Minutes](https://learnxinyminutes.com/): one executable tour for
orientation before the chapters explain each idea in depth.
