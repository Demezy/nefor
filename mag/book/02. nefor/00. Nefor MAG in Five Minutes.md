# Nefor MAG in Five Minutes

This guide assumes [MAG in Five Minutes](<../01. core/00. MAG in Five Minutes.md>).
It builds one increasingly capable Nefor program: first one agent, then a
project-specific development cycle, then a dynamically sized swarm. Read it
from top to bottom; every binding contributes to the final artifact.

```lisp
(require "nefor.actors")
(require "nefor.artifact")
(require "nefor.contracts")
(require "nefor.dynamic")
(require "nefor.graph")
(require "nefor.shell")
(require "nefor.worktree")

;; A reasoner is anything with the typed shape Context -> Context: an agent,
;; deterministic command, human decision, or complete workflow. A graph of
;; reasoners has the same outer shape, so it can become one reasoner inside a
;; larger graph. In this Nefor application, nodes represent reasoners. MAG
;; itself knows neither term; Nefor's libraries define both as ordinary data.

;; Start with one agent. The function returns a Node I (O | AgentError), and
;; calling it only constructs immutable graph data. Nothing executes yet.
(let one-agent
  (fn [I O] [[id String] [system String]
             [input-type (TypeTag I)] [input-wire String]
             [output-type (TypeTag O)]
             [tools (List String)] [policy nefor.contracts.DaPolicy]]
    -> (nefor.graph.Node I (| O nefor.contracts.AgentError))
    (nefor.actors.agent
      (as nefor.actors.AgentConfig
        {:id id
         :model (nefor.contracts.no-identifier)
         :profile (nefor.contracts.identifier "standard")
         :provider "chatgpt"
         :system system
         :tools tools
         :da-policy policy
         :max-corrections 2})
      input-type input-wire output-type)))

;; Project-local types make every branch of this development cycle explicit.
;; The builder accepts one serialized development context or typed feedback
;; from later steps. Task + Worktree remains a product until a small adapter
;; turns that complete value into ProviderInput.
(type BuildPassed {:tag String :stdout String})
(type BuildFailed {:tag String :stdout String :stderr String :status Int})
(type BuildFeedback (| BuildPassed BuildFailed))
(type NeedChanges {:feedback String})
(type Approved {:summary String})
(type BuilderInput
  (| nefor.contracts.ProviderInput BuildFailed NeedChanges))
(type ReviewDecision (| Approved NeedChanges))
(type DevelopmentComplete {:summary String :worktree String})

;; The command and worktree are properties of this repository, not Nefor
;; primitives. Bind them once and reuse them wherever the workflow needs the
;; exact same value.
(let repository ".")
(let worktree-path "tmp/mag-book-sdlc")
(let build-command "cargo build")
(let build-passed-tag "main.BuildPassed")
(let build-failed-tag "main.BuildFailed")
(let builder-policy
  (nefor.contracts.da-policy
    (assoc (as (Map String String) {}) build-command "deny")))

;; A task-local constructor can package a low-level canonical actor as a new
;; reusable Node. This adapter waits for every occurrence of its product input,
;; then serializes that complete value for an agent.
(let provider-context
  (fn [T] [[id String] [input-type (TypeTag T)] [input-wire String]]
    -> (nefor.graph.Node T nefor.contracts.ProviderInput)
    (let input (nefor.graph.port id input-type input-wire))
    (let output
      (nefor.graph.port id (type-tag nefor.contracts.ProviderInput)
        "generic-provider.ProviderOut"))
    (nefor.graph.node id "ordinary"
      [(nefor.graph.actor id nefor.actors.adapter-factory
         [(type-evidence input-type)]
         (as nefor.actors.AdapterParams
           {:seed "provider-in" :schema (type-schema input-type)})
         (nefor.graph.store-port input)
         [(nefor.graph.store-port output)])]
      (as (List nefor.graph.StoredRoute) [])
      (as (List nefor.graph.Message) [])
      input output)))

;; The library's delta-route shorthand takes equal source and destination
;; types. This local variant retains their distinct types; the product/union
;; compatibility is then reflected by lowering's product positions.
(let delta-route-into
  (fn [A B] [[change nefor.graph.Delta]
             [from (nefor.graph.Port A)] [to (nefor.graph.Port B)]]
    -> nefor.graph.Delta
    (as nefor.graph.Delta
      {:actors (get change "actors")
       :routes (concat (get change "routes")
                 [(nefor.graph.stored-route from to)])
       :messages (get change "messages")
       :kills (get change "kills")})))

;; worktree is Node Unit Worktree. Its typed output joins the task at the
;; context adapter, while the same bound path configures the deterministic
;; check.
(let worktree
  (nefor.worktree.create "development-worktree"
    (as nefor.worktree.CreateSpec
      {:repository repository
       :path worktree-path
       :branch "mag-book-sdlc"
       :base "main"})))
(let builder-context
  (provider-context "builder-context"
    (type-tag (+ nefor.contracts.Task nefor.worktree.Worktree))
    "task"))
(let builder
  (one-agent "builder"
    (str
      "Implement the supplied task in the supplied worktree. Do not run "
      (str build-command
        "; the workflow runs it deterministically and returns typed failures."))
    (type-tag BuilderInput)
    "task"
    (type-tag nefor.contracts.TextAnswer)
    nefor.actors.general-tools
    builder-policy))
(let build
  (nefor.shell.script "build"
    (as nefor.shell.ShellScriptParams
      {:script build-command
       :cwd worktree-path
       :timeout (nefor.contracts.no-timeout)})))
(let reviewer
  (one-agent "reviewer"
    "Review the completed work and return Approved or NeedChanges."
    (type-tag BuildPassed)
    "task"
    (type-tag ReviewDecision)
    nefor.actors.read-only-tools
    (nefor.contracts.no-da-policy)))
(let development-result
  (nefor.graph.output "development-result" (type-tag DevelopmentComplete)))

;; A resident function is a pure runtime mapper. It receives the builder's
;; TextAnswer and returns a Delta that activates the deterministic build node.
(let run-build
  (fn [[answer nefor.contracts.TextAnswer]] -> Artifact
    (nefor.artifact.delta
      (nefor.graph.delta-message
        (nefor.graph.delta
          (as (List nefor.graph.Actor) [])
          (as (List nefor.graph.StoredRoute) [])
          (as (List nefor.graph.Message) [])
          (as (List String) []))
        (get build "input")
        (as (| Unit nefor.contracts.Text)
          (as nefor.contracts.Text {:content answer}))))))

;; ProcessResult is data, including nonzero exit status. This task-local
;; one-liner maps its concrete shape into the cycle's own enum-like variants.
(let classify-build
  (fn [[result nefor.contracts.ProcessResult]] -> BuildFeedback
    (let termination (get result "termination"))
    (if (if (= (get termination "kind") "exit")
            (= (get termination "value") 0)
            false)
      (as BuildFeedback
        (as BuildPassed {:tag build-passed-tag
                         :stdout (get result "stdout")}))
      (as BuildFeedback
        (as BuildFailed
          {:tag build-failed-tag
           :stdout (get result "stdout")
           :stderr (get result "stderr")
           :status (get termination "value")})))))

;; The mapping decides where the next typed value goes: success to the
;; reviewer, failure back to the ordinary builder input.
(let route-build-result
  (fn [[result nefor.contracts.ProcessResult]] -> Artifact
    (let feedback (classify-build result))
    (if (= (get feedback "tag") build-passed-tag)
      (nefor.artifact.delta
        (nefor.graph.delta-message
          (nefor.graph.delta
            (as (List nefor.graph.Actor) [])
            (as (List nefor.graph.StoredRoute) [])
            (as (List nefor.graph.Message) [])
            (as (List String) []))
          (get reviewer "input")
          (as BuildPassed feedback)))
      (nefor.artifact.delta
        (nefor.graph.delta-message
          (nefor.graph.delta
            (as (List nefor.graph.Actor) [])
            (as (List nefor.graph.StoredRoute) [])
            (as (List nefor.graph.Message) [])
            (as (List String) []))
          (get builder "input")
          (as BuilderInput (as BuildFailed feedback)))))))

;; Review feedback enters the same BuilderInput union. Approval closes the
;; cycle with a value that a larger workflow can consume.
(let revise
  (fn [[change NeedChanges]] -> Artifact
    (nefor.artifact.delta
      (nefor.graph.delta-message
        (nefor.graph.delta
          (as (List nefor.graph.Actor) [])
          (as (List nefor.graph.StoredRoute) [])
          (as (List nefor.graph.Message) [])
          (as (List String) []))
        (get builder "input")
        (as BuilderInput change)))))
(let finish-development
  (fn [[approval Approved]] -> Artifact
    (nefor.artifact.delta
      (nefor.graph.delta-message
        (nefor.graph.delta
          (as (List nefor.graph.Actor) [])
          (as (List nefor.graph.StoredRoute) [])
          (as (List nefor.graph.Message) [])
          (as (List String) []))
        (get development-result "input")
        (as DevelopmentComplete
          {:summary (get approval "summary") :worktree worktree-path})))))

;; Package the now-large cycle behind a small typed boundary. ResidentWorkflow
;; is this program's concrete data representation for one composed reasoner;
;; sdlc is the task-local function constructing it.
(type ResidentWorkflow [I O]
  {:delta nefor.graph.Delta
   :rules (List nefor.graph.Rule)
   :input (nefor.graph.Port I)
   :output (nefor.graph.Port O)})
(let sdlc
  (fn [[task String]] -> (ResidentWorkflow Unit DevelopmentComplete)
    (let task-source (nefor.actors.task-source "development-task" task))
    (as (ResidentWorkflow Unit DevelopmentComplete)
      {:delta
       (nefor.graph.delta-message-front
         (delta-route-into
           (delta-route-into
             (delta-route-into
               (nefor.graph.merge-delta
                 (nefor.graph.node-delta task-source)
                 (nefor.graph.merge-delta
                   (nefor.graph.node-delta worktree)
                   (nefor.graph.merge-delta
                     (nefor.graph.node-delta builder-context)
                     (nefor.graph.merge-delta
                       (nefor.graph.node-delta builder)
                       (nefor.graph.merge-delta
                         (nefor.graph.node-delta build)
                         (nefor.graph.merge-delta
                           (nefor.graph.node-delta reviewer)
                           (nefor.graph.node-delta development-result)))))))
               (get task-source "output")
               (get builder-context "input"))
             (get worktree "output")
             (get builder-context "input"))
           (get builder-context "output")
           (get builder "input"))
         (get worktree "input") nil)
       :rules
       [(nefor.graph.rule "run-build"
          (nefor.actors.result-arm builder
            (type-tag nefor.contracts.TextAnswer))
          "run-build")
        (nefor.graph.rule "route-build-result" (get build "output")
          "route-build-result")
        (nefor.graph.rule "revise"
          (nefor.actors.result-arm reviewer (type-tag NeedChanges))
          "revise")
        (nefor.graph.rule "finish-development"
          (nefor.actors.result-arm reviewer (type-tag Approved))
          "finish-development")]
       :input (get worktree "input")
       :output (get development-result "output")})))

;; All of the task-specific machinery above is now one ordinary value.
(let development (sdlc "Implement and review the requested repository change."))

;; A later node uses that reasoner's output to decide the size and shape of a
;; swarm at runtime. The number of workers is not known while MAG compiles.
(type SwarmTask {:title String :instructions String})
(type WorkerResult {:title String :finding String})
(type SwarmSummary {:content String})
(type IndexedTask {:index Int :value SwarmTask})
(let planner
  (one-agent "planner"
    "Derive the independent follow-up investigations from the completed work."
    (type-tag DevelopmentComplete)
    "task"
    (type-tag (List SwarmTask))
    nefor.actors.read-only-tools
    (nefor.contracts.no-da-policy)))
(let collected
  (nefor.dynamic.collected-prompt "swarm-results"
    (type-tag (| WorkerResult nefor.contracts.AgentError))))
(let integrator
  (one-agent "integrator"
    "Integrate the dynamically produced worker findings."
    (type-tag nefor.contracts.ProviderInput)
    "generic-provider.ProviderOut"
    (type-tag SwarmSummary)
    nefor.actors.read-only-tools
    (nefor.contracts.no-da-policy)))
(let final-result
  (nefor.graph.output "result"
    (type-tag (| SwarmSummary nefor.contracts.AgentError))))

(let indexed-task
  (fn [[index Int] [task SwarmTask]] -> IndexedTask
    (as IndexedTask {:index index :value task})))
(let worker-id
  (fn [[entry IndexedTask]] -> String
    (str "swarm.worker." (get entry "index"))))
(let make-worker
  (fn [[entry IndexedTask]]
    -> (nefor.graph.Node SwarmTask
         (| WorkerResult nefor.contracts.AgentError))
    (let task (get entry "value"))
    (one-agent (worker-id entry)
      (get task "instructions")
      (type-tag SwarmTask)
      "task"
      (type-tag WorkerResult)
      nefor.actors.read-only-tools
      (nefor.contracts.no-da-policy))))
(let add-worker
  (fn [[collector-input
          (nefor.graph.Port (| WorkerResult nefor.contracts.AgentError))]
       [change nefor.graph.Delta]
       [entry IndexedTask]] -> nefor.graph.Delta
    (let worker (make-worker entry))
    (nefor.graph.delta-message-front
      (nefor.graph.delta-route
        (nefor.graph.merge-delta change (nefor.graph.node-delta worker))
        (get worker "output") collector-input)
      (get worker "input") (get entry "value"))))

;; This resident rule receives the planner's actual List SwarmTask. indexed-map
;; gives each item a stable position; fold creates exactly that many agents and
;; routes them through one collector. [] bypasses the collector explicitly.
(let expand-swarm
  (fn [[tasks (List SwarmTask)]] -> Artifact
    (if (= (count tasks) 0)
      (nefor.artifact.delta
        (nefor.graph.delta
          (as (List nefor.graph.Actor) [])
          (as (List nefor.graph.StoredRoute) [])
          [(nefor.dynamic.empty-to (get collected "input"))]
          (as (List String) [])))
      ((fn [] -> Artifact
        (let indexed (indexed-map indexed-task tasks))
        (let sender-ids
          (map
            (fn [[entry IndexedTask]] -> String
              (str (worker-id entry) ".llm"))
            indexed))
        (let collector
          (nefor.dynamic.collector "swarm.collector" sender-ids
            (type-tag (| WorkerResult nefor.contracts.AgentError))))
        (let workers
          (fold
            (fn [[change nefor.graph.Delta] [entry IndexedTask]]
              -> nefor.graph.Delta
              (add-worker (get collector "input") change entry))
            (nefor.graph.node-delta collector)
            indexed))
        (nefor.artifact.delta
          (nefor.graph.delta-route workers
            (get collector "output") (get collected "input"))))))))

;; The final initial modification contains the named SDLC reasoner and the
;; static part of the swarm. Lowering expands every high-level Node into the
;; low-level actors and routes the kernel knows how to execute.
(let initial
  (nefor.graph.delta-route
    (nefor.graph.delta-route
      (nefor.graph.delta-route
        (nefor.graph.merge-delta
          (get development "delta")
          (nefor.graph.merge-delta
            (nefor.graph.node-delta planner)
            (nefor.graph.merge-delta
              (nefor.graph.node-delta collected)
              (nefor.graph.merge-delta
                (nefor.graph.node-delta integrator)
                (nefor.graph.node-delta final-result)))))
        (get development "output") (get planner "input"))
      (get collected "output") (get integrator "input"))
    (get integrator "output") (get final-result "input")))

(artifact
  (nefor.graph.lower-resident
    initial
    (concat
      (get development "rules")
      [(nefor.graph.rule "expand-swarm"
         (nefor.actors.result-arm planner (type-tag (List SwarmTask)))
         "expand-swarm")])
    (get final-result "output")))
```

The authored hierarchy is for understanding and reuse: an agent becomes a
node, the SDLC becomes one `Reasoner`, and that reasoner feeds a dynamic swarm.
The artifact contains only the flattened actors, routes, messages, resident
rules, types, and result boundary that Nefor executes.
