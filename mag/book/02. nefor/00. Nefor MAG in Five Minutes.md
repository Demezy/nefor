# Nefor MAG in Five Minutes

This guide assumes [MAG in Five Minutes](<../01. core/00. MAG in Five Minutes.md>).
MAG supplies typed immutable data, ordinary functions, nominal algebraic data
types, and one artifact value. Nefor's libraries use those mechanisms to build
nodes, agents, deterministic commands, worktrees, products, fixed parallel
work, and runtime-sized consumers. None introduces graph-specific syntax.

> **Scope:** This guide teaches MAG and Nefor library composition only; prompts, task decomposition, review policy, permissions, and domain practice are intentionally simplified and are not prescriptions.

The smallest complete program imports the facade, constructs one root-capable
node, and closes it directly:

```mag
import nefor

compile_graph(script("hello", ShellScriptParams {
  script: "printf 'hello\\n'",
  cwd: ".",
  timeout: timeout_ms(30000),
}))
```

`script(...)` has type `Node<Unit, ProcessResult>`. Constructing it runs
nothing; `compile_graph` adds the output boundary, validates the graph, and
returns its immutable artifact. At runtime an exposed, unfed `Unit` input gets
one activation, while a fed node waits for its dependency.

The next program grows that root into a typed development workflow, then adds
runtime-sized follow-up work. Read it top to bottom.

```mag
import agents.{}
import core.map.{}
import core.types.{}
import nefor.actors.{}
import nefor.agents.{}
import nefor.artifact.{}
import nefor.contracts.{}
import nefor.dynamic.{}
import nefor.graph.{}
import nefor.node.{}
import nefor.result.{}
import nefor.shell.{}
import nefor.worktree.{}

// Agents should speak in application types, not generic text envelopes.
newtype LineNumber = Int
type ReviewComment {path: String, line: LineNumber, body: String}
type Review {summary: String, comments: List<ReviewComment>}
type Implementation {summary: String}
type Approved {review: Review}
type NeedChanges {review: Review}
type Followup {title: String, instructions: String}
type Finding {title: String, finding: String}
type FinalSummary {summary: String}

type DevelopmentConfig {
  repository: String,
  worktree: String,
  branch: String,
  base: String,
  build: String
}

// IDs are primitive placement identities; reusable behavior stays in config.
// Mapping one config over IDs produces same-shaped nodes, and sequence sends
// one shared Task to every node and returns results in ID-list order.
let reviewer_config = agents.AgentConfig {
  model: agents.standard,
  system: "Review the task.",
  tools: nefor.actors.read_only_tools,
  tool_approval_policy: nefor.contracts.no_tool_approval_policy(),
  max_corrections: 2
}
let review_ids = ["security-review", "test-review"]
let review_nodes = map(
  ((|id| => agents.agent<nefor.contracts.Task, Review>(id, reviewer_config)): fn(String) -> nefor.graph.Node<nefor.contracts.Task, core.types.Result<nefor.contracts.AgentError, Review>>),
  review_ids,
)
let parallel_reviews = nefor.node.sequence(review_nodes)

// A reusable workflow is an ordinary function returning one Node boundary.
// The primitive id is separate from repository-specific reusable config.
let development_workflow: fn(String, DevelopmentConfig) -> nefor.graph.Node<nefor.contracts.Task, core.types.Result<nefor.contracts.AgentError, Review>> = |id, config| => {
  let task = nefor.graph.identity(str(id, ".task"), type_tag<nefor.contracts.Task>())

  let create = nefor.worktree.create(str(id, ".worktree"), nefor.worktree.CreateSpec {
    repository: get(config, "repository"),
    path: get(config, "worktree"),
    branch: get(config, "branch"),
    base: get(config, "base")
  })
  let create_after_task = nefor.graph.identity(str(id, ".worktree-trigger"), type_tag<nefor.contracts.Task>()) `*>` create
  let implementation_input = task `&&&` create_after_task

  let implementer = agents.agent<(nefor.contracts.Task, nefor.worktree.Worktree), Implementation>(str(id, ".implementer"), agents.AgentConfig {
    model: agents.standard,
    system: "Implement the task in its worktree.",
    tools: nefor.actors.general_tools,
    tool_approval_policy: nefor.contracts.no_tool_approval_policy(),
    max_corrections: 2
  })
  let implemented = implementation_input `>>>` implementer

  // Pair each successful implementation with its bounded deterministic build.
  let build = nefor.shell.script(str(id, ".build"), nefor.shell.ShellScriptParams {
    script: get(config, "build"),
    cwd: get(config, "worktree"),
    timeout: nefor.contracts.timeout_ms(120000)
  })
  let implementation = nefor.graph.identity(str(id, ".implementation"), type_tag<Implementation>())
  let build_after_implementation = nefor.graph.identity(str(id, ".build-trigger"), type_tag<Implementation>()) `*>` build
  let implementation_and_build = implementation `&&&` build_after_implementation
  let built = nefor.result.map(implemented, implementation_and_build)

  let reviewer = agents.agent<(nefor.contracts.Task, core.types.Result<nefor.contracts.AgentError, (Implementation, nefor.contracts.ProcessResult)>), Review>(str(id, ".reviewer"), reviewer_config)

  // identity preserves original intent; &&& sends the same task through both
  // branches; the product emits only after both task and implementation result exist.
  let review_input = task `&&&` built
  let reviewed = review_input `>>>` reviewer

  // map_error transforms only Error. Identity makes the channel explicit here;
  // a real workflow can substitute a domain-specific error normalizer.
  let same_error = nefor.graph.identity(str(id, ".same-error"), type_tag<nefor.contracts.AgentError>())
  nefor.node.named(id, nefor.result.map_error(reviewed, same_error))
}

let development_task = nefor.graph.source("development-task", nefor.contracts.Task {
  prompt: "Implement and review the requested repository change."
})
let development = development_workflow("development", DevelopmentConfig {
  repository: ".",
  worktree: "tmp/mag-book-worktree",
  branch: "mag-book-work",
  base: "main",
  build: "cargo build"
})
let reviewed = development_task `>>>` development

// >=> binds Result-producing nodes: Error passes through unchanged and only Ok
// enters the continuation. choose branches over nominal Either and repacks it.
let decide = agents.agent<Review, core.types.Either<Approved, NeedChanges>>("decide", agents.AgentConfig {
  model: agents.standard,
  system: "Classify the review.",
  tools: nefor.actors.read_only_tools,
  tool_approval_policy: nefor.contracts.no_tool_approval_policy(),
  max_corrections: 2
})
let decided = nefor.result.`>=>`(reviewed, decide)
let approved = nefor.graph.identity("approved", type_tag<Approved>())
let changes = nefor.graph.identity("need-changes", type_tag<NeedChanges>())
let branched = nefor.result.map(decided, nefor.node.choose("decision", approved, changes))

// Runtime cardinality is different from sequence's compile-time List. The
// planner emits DynamicList<Followup>; refs define one closed worker template.
let occurrence = nefor.dynamic.trigger_ref(type_tag<nefor.dynamic.Indexed<Followup>>())
let collection = nefor.dynamic.field_ref(occurrence, "collection", type_tag<String>())
let index = nefor.dynamic.field_ref(occurrence, "index", type_tag<Int>())
let followup = nefor.dynamic.field_ref(occurrence, "value", type_tag<Followup>())
let instructions = nefor.dynamic.field_ref(followup, "instructions", type_tag<String>())
let index_text = nefor.dynamic.int_to_decimal_string_ref(index)
let worker_id = nefor.dynamic.concat_strings_ref([nefor.dynamic.capture_ref("followup.worker."), index_text])
let worker_root = nefor.dynamic.concat_strings_ref([nefor.dynamic.capture_ref("followups-"), index_text])
let worker_template = agents.dynamic_template<Finding>("followups", agents.DynamicTemplateConfig {
  model: agents.standard,
  tools: nefor.actors.read_only_tools,
  tool_approval_policy: nefor.contracts.no_tool_approval_policy(),
  max_corrections: 2
}, collection, index, worker_id, worker_root, instructions)

let planner = agents.dynamic_agent<core.types.Either<Approved, NeedChanges>, Followup>("planner", agents.AgentConfig {
  model: agents.standard,
  system: "Return ordered follow-up investigations.",
  tools: nefor.actors.read_only_tools,
  tool_approval_policy: nefor.contracts.no_tool_approval_policy(),
  max_corrections: 2
})
let planned = nefor.result.`>=>`(branched, planner)

// traverse_template handles every indexed occurrence and preserves explicit
// completion. context then emits one ordered provider context, even when empty.
let workers = nefor.dynamic.traverse_template("followups", worker_template, type_tag<Followup>(), type_tag<core.types.Result<nefor.contracts.AgentError, Finding>>())
let investigated = nefor.result.`>=>`(planned, nefor.result.lift("workers-result", type_tag<nefor.contracts.AgentError>(), workers))
let result_context = nefor.dynamic.context("followup-context", type_tag<core.types.Result<nefor.contracts.AgentError, Finding>>())
let integrator = agents.agent<nefor.contracts.ProviderInput, FinalSummary>("integrator", agents.AgentConfig {
  model: agents.standard,
  system: "Integrate the ordered findings.",
  tools: nefor.actors.read_only_tools,
  tool_approval_policy: nefor.contracts.no_tool_approval_policy(),
  max_corrections: 2
})
let production = nefor.result.`>=>`(investigated, result_context `>>>` integrator)

// sequence shares Unit across fixed checks and preserves their order. Binary <*
// waits for those checks but retains the summary; it is not an applicative list.
let build_check = nefor.shell.script("verification.build", nefor.shell.ShellScriptParams {script: "cargo build", cwd: ".", timeout: nefor.contracts.timeout_ms(120000)})
let test_check = nefor.shell.script("verification.test", nefor.shell.ShellScriptParams {script: "cargo test", cwd: ".", timeout: nefor.contracts.timeout_ms(120000)})
let fixed_checks = nefor.node.sequence([build_check, test_check])
let retain_summary = nefor.graph.identity("verification.summary", type_tag<FinalSummary>()) `<*` fixed_checks
let verified = nefor.result.map(production, retain_summary)

nefor.artifact.compile_graph(verified)
```

`Node<I, O>` is the reusable boundary. `>>>` feeds ordinary output to input;
`*>` runs a `Unit`-input node after the left and keeps the right result; binary
`<*` also waits for the right but keeps the left result. `&&&` sends one input
to both branches and joins their outputs; `***` maps two nodes over a product;
`+++` maps them over nominal `Either`. These operators and `named`, `choose`,
and `sequence` are ordinary functions returning nodes.

`sequence(nodes)` accepts a compile-time `List<Node<I, O>>`. Every child gets
the same `I`, and the output is an ordered `List<O>`. `DynamicList<T>` instead
records runtime-discovered indexed occurrences and completion:
`traverse_template` consumes each occurrence, while `context` consumes the
completed ordered collection.

Agents return `core.types.Result<AgentError, O>`. `nefor.result.map` transforms
only `Ok`, `map_error` transforms only `Error`, and `>=>` chains two
Result-producing nodes without IDs at the call site. Deterministic nodes enter
the same channel through `lift`.

Logical names are local path segments, independent of opaque runtime actor IDs.
`rename` changes one displayed segment; `named` creates an expandable hierarchy
boundary. A full logical path must be unique in one run, and dots inside an
actor ID do not create hierarchy levels.
