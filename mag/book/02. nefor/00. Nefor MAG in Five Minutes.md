# Nefor MAG in Five Minutes

This guide assumes [MAG in Five Minutes](<../01. core/00. MAG in Five Minutes.md>).
MAG supplies typed immutable data, ordinary functions, nominal algebraic data
types, and one artifact value. Nefor's libraries use those mechanisms to build
nodes, agents, deterministic commands, worktrees, products, fixed parallel
work, and runtime-sized consumers. None of them introduce graph-specific
language syntax.

The program below grows one root-capable node into a reusable development
workflow with dynamically many follow-up workers. Read it from top to bottom:
each section adds ordinary typed values and functions, and the final
`compile_graph` call closes the terminal node into an artifact.

```mag
import agents.{}
import core.map.{}
import core.types.{}
import nefor.actors.{}
import nefor.agents.{}
import nefor.artifact.{}
import nefor.contracts.{}
import nefor.dynamic.{}
import nefor.graph.{}
import nefor.node.{}
import nefor.shell.{}
import nefor.worktree.{}

// Application types remain ordinary nominal MAG data. Nefor does not prescribe
// an SDLC or its review vocabulary.
type Approved {summary: String}
type NeedChanges {feedback: String}
type Followup {title: String, instructions: String}
type Finding {title: String, finding: String}
type FinalSummary {summary: String}
type VerificationConfig {id: String, cwd: String}
type DevelopmentConfig {
  id: String,
  repository: String,
  worktree: String,
  branch: String,
  base: String,
  build: String
}

let build_command = "cargo build"

// Fixed parallelism is an ordinary node-producing function too. sequence fixes
// command count and result order at compile time; fanout retains the input and
// joins it with the complete ordered result List.
let verification<I>: fn(VerificationConfig, TypeTag<I>) -> nefor.graph.Node<I, (List<nefor.contracts.ProcessResult>, I)> = |config, input_type| => {
  let id = get(config, "id")
  let build = nefor.shell.script(str(id, ".build"), nefor.shell.ShellScriptParams {script: "cargo build", cwd: get(config, "cwd"), timeout: nefor.contracts.timeout_ms(120000)})
  let test = nefor.shell.script(str(id, ".test"), nefor.shell.ShellScriptParams {script: "cargo test", cwd: get(config, "cwd"), timeout: nefor.contracts.timeout_ms(120000)})
  let fixed_checks = nefor.node.sequence(str(id, ".checks"), [build, test])
  let value = nefor.graph.identity(str(id, ".value"), input_type)
  let checks_after_value = nefor.node.`*>`(str(id, ".after-value"), value, fixed_checks)
  let retained = nefor.graph.identity(str(id, ".retained"), input_type)
  nefor.node.named(id, nefor.node.fanout(str(id, ".joined"), checks_after_value, retained))
}

// A reusable workflow is an ordinary function returning one Node boundary.
// Its callers need not know that it creates a worktree, joins it with the task,
// delegates implementation, runs a bounded command, and performs review.
let development_workflow: fn(DevelopmentConfig) -> nefor.graph.Node<nefor.contracts.Task, core.types.Result<nefor.contracts.AgentError, core.types.Either<Approved, NeedChanges>>> = |config| => {
  let id = get(config, "id")
  let task_value = nefor.node.rename("task", nefor.graph.identity(str(id, ".task"), type_tag<nefor.contracts.Task>()))

  let worktree = nefor.node.rename("create", nefor.worktree.create(str(id, ".worktree"), nefor.worktree.CreateSpec {
    repository: get(config, "repository"),
    path: get(config, "worktree"),
    branch: get(config, "branch"),
    base: get(config, "base")
  }))
  let worktree_trigger = nefor.node.rename("trigger", nefor.graph.identity(str(id, ".worktree-trigger"), type_tag<nefor.contracts.Task>()))
  let worktree_after_task = nefor.node.rename("worktree", nefor.node.`*>`(str(id, ".create-worktree"), worktree_trigger, worktree))

  // fanout sends the same Task down both paths and joins their outputs into the
  // ordered product (Task, Worktree). The builder cannot run before both exist.
  let builder_input = nefor.node.rename("input", nefor.node.fanout(str(id, ".input"), task_value, worktree_after_task))
  let policy_rules = core.map.insert((core.map.empty(type_tag<String>()): Map<String, String>), get(config, "build"), "deny")
  let builder = nefor.node.rename("builder", nefor.actors.agent(agents.resolve_model, nefor.actors.AgentConfig<agents.Model> {
    id: str(id, ".builder"),
    model: agents.standard,
    system: str("Implement the task in its worktree. Do not run ", str(get(config, "build"), "; the workflow runs it deterministically.")),
    tools: nefor.actors.general_tools,
    da_policy: nefor.contracts.da_policy(policy_rules),
    max_corrections: 2
  }, type_tag<(nefor.contracts.Task, nefor.worktree.Worktree)>(), type_tag<nefor.contracts.TextAnswer>()))

  // Shell execution is an ordinary Node<Unit, ProcessResult>. A finite timeout
  // bounds this deterministic capability; constructing it still runs nothing.
  let build = nefor.node.rename("build", nefor.shell.script(str(id, ".build"), nefor.shell.ShellScriptParams {
    script: get(config, "build"),
    cwd: get(config, "worktree"),
    timeout: nefor.contracts.timeout_ms(120000)
  }))
  let builder_answer = nefor.node.rename("answer", nefor.graph.identity(str(id, ".builder-answer"), type_tag<nefor.contracts.TextAnswer>()))
  let build_after_builder = nefor.node.rename("build-after-builder", nefor.node.`*>`(str(id, ".build-after-builder"), builder_answer, build))

  // ProcessResult includes stdout, stderr, and a nominal exit-or-signal sum. A
  // nonzero command is business data here; the reviewer owns its policy.
  let reviewer = nefor.node.rename("reviewer", nefor.agents.with_tools(agents.resolve_model, agents.standard, str(id, ".reviewer"), "Review the deterministic build result. Return Left Approved or Right NeedChanges.", nefor.actors.read_only_tools, type_tag<nefor.contracts.ProcessResult>(), type_tag<core.types.Either<Approved, NeedChanges>>(), 2))

  // Agents already return Result<AgentError, T>. Deterministic nodes enter that
  // same channel through lift_result, and >=> binds only Ok to the continuation.
  let prepared = nefor.node.`>>>`(builder_input, builder)
  let built = nefor.node.`>=>`(prepared, nefor.node.lift_result(str(id, ".build-result"), type_tag<nefor.contracts.AgentError>(), build_after_builder))
  nefor.node.named(id, nefor.node.`>=>`(built, reviewer))
}

// Linear composition connects ordinary node values. Composition remains
// transparent; named above is the deliberate expandable hierarchy boundary.
let development_task = nefor.actors.task_source("development-task", "Implement and review the requested repository change.")
let development = development_workflow(DevelopmentConfig {
  id: "development",
  repository: ".",
  worktree: "tmp/mag-book-worktree",
  branch: "mag-book-work",
  base: "main",
  build: build_command
})
let developed = nefor.node.`>>>`(development_task, development)

// choose is runtime branching over nominal Either. Each constructor is
// unpacked, routed through its branch, and repacked explicitly.
let approved = nefor.graph.identity("approved", type_tag<Approved>())
let changes = nefor.graph.identity("need-changes", type_tag<NeedChanges>())
let decision = nefor.node.choose("decision", approved, changes)
let branched = nefor.node.`>=>`(developed, nefor.node.lift_result("decision-result", type_tag<nefor.contracts.AgentError>(), decision))

// Runtime cardinality is different from a compile-time List. The planner emits
// DynamicList<Followup>; references describe a closed per-occurrence template
// and do not execute while MAG compiles.
let occurrence = nefor.dynamic.trigger_ref(type_tag<nefor.dynamic.Indexed<Followup>>())
let collection = nefor.dynamic.field_ref(occurrence, "collection", type_tag<String>())
let index = nefor.dynamic.field_ref(occurrence, "index", type_tag<Int>())
let followup = nefor.dynamic.field_ref(occurrence, "value", type_tag<Followup>())
let instructions = nefor.dynamic.field_ref(followup, "instructions", type_tag<String>())
let index_text = nefor.dynamic.int_to_decimal_string_ref(index)
let worker_id = nefor.dynamic.concat_strings_ref([nefor.dynamic.capture_ref("followup.worker.", type_tag<String>()), index_text])
let worker_root = nefor.dynamic.concat_strings_ref([nefor.dynamic.capture_ref("followups-", type_tag<String>()), index_text])
let worker_template = nefor.agents.dynamic_template_with_tools(agents.resolve_model, agents.standard, "followups", collection, index, worker_id, worker_root, instructions, nefor.actors.read_only_tools, type_tag<Finding>(), 2)

let planner = nefor.agents.dynamic_with_tools(agents.resolve_model, agents.standard, "planner", "Return the ordered follow-up investigations.", nefor.actors.read_only_tools, type_tag<core.types.Either<Approved, NeedChanges>>(), type_tag<Followup>(), 2)
let planned = nefor.node.`>=>`(branched, planner)

// traverse-template consumes every indexed occurrence. Its output remains a
// DynamicList, preserving explicit completion for downstream consumers.
let workers = nefor.dynamic.traverse_template("followups", worker_template, type_tag<Followup>(), type_tag<core.types.Result<nefor.contracts.AgentError, Finding>>())
let investigated = nefor.node.`>=>`(planned, nefor.node.lift_result("workers-result", type_tag<nefor.contracts.AgentError>(), workers))

// context is the complementary completed-list consumer: after completion it
// emits one ordered provider context, including for an empty collection.
let result_context = nefor.dynamic.context("followup-context", type_tag<core.types.Result<nefor.contracts.AgentError, Finding>>())
let integrator = nefor.agents.with_tools(agents.resolve_model, agents.standard, "integrator", "Integrate every ordered finding into one summary.", nefor.actors.read_only_tools, type_tag<nefor.contracts.ProviderInput>(), type_tag<FinalSummary>(), 2)
let integrate = nefor.node.`>>>`(result_context, integrator)
let production = nefor.node.`>=>`(investigated, integrate)

// The fixed checks are part of the same linear Result pipeline. Their shell
// nodes are bounded, and their product retains both ordered facts and summary.
let fixed_verification = verification(VerificationConfig {id: "verification", cwd: "."}, type_tag<FinalSummary>())
let verified = nefor.node.`>=>`(production, nefor.node.lift_result("verification-result", type_tag<nefor.contracts.AgentError>(), fixed_verification))

// compile_graph is the generic one-terminal artifact boundary. It adds the
// ordinary output node, validates the graph, and emits the immutable program.
nefor.artifact.compile_graph(verified)
```

`Node<I, O>` is the reusable boundary throughout. Constructing one runs
nothing: its ports are typed connection points in immutable data. At lowering,
an exposed and unfed `Unit` input receives one activation; a fed node waits for
its dependency, and nested actors are not independently started.

The important scale transition is not a new graph language.
`development_workflow` is an ordinary function returning one node. `named`
records its meaningful hierarchy, while `>>>`, `>=>`, `*>`, `fanout`, `choose`,
and `sequence` are ordinary functions returning nodes. Expanding `development`
reveals the worktree, builder, deterministic build, and reviewer; expanding
`builder` reveals its `entry`, `llm`, `run-tool`, and `tool-result`
actors.

The two collection mechanisms preserve different facts. `sequence` accepts a
compile-time `List<Node<I, O>>`, so cardinality and output order are fixed in the
artifact. `DynamicList<T>` records runtime-discovered indexed occurrences and
explicit completion. `traverse_template` consumes each occurrence, while
`context` consumes the completed ordered collection.

Failures and branches are nominal data. Agents return
`core.types.Result<AgentError, O>`; `>=>` forwards `Error` unchanged and sends
only `Ok` to its continuation. `choose` similarly unpacks and repacks the two
constructors of `core.types.Either`, so no route pretends that a constructor is
a transparent structural record.

Logical names are local path segments, independent of opaque runtime actor ids.
`rename` changes only a displayed segment. A full path such as
`["development", "builder", "llm"]` must be unique in one run; a dot inside
an actor id does not create another hierarchy level.
