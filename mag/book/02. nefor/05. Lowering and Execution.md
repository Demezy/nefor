# Lowering and Execution

As MAG compiles into an artifact, Nefor's graph library can perform domain
validation before the actor runtime receives a modification.

## Validation moves failures left

Node identity, typed boundaries, source/output shape, product coverage, runtime
contracts, reachability, and resident rule outputs are checked during
construction and lowering. Encoding computations as typed data makes invalid
states fail compilation whenever the required fact is available there,
reducing the failures left for runtime.

The implementation is in
[`nefor/graph.mag`](../../lib/nefor/graph.mag)
and
[`nefor/artifact.mag`](../../lib/nefor/artifact.mag).

## Lowering

Applying `lower` expands the previously defined graph values:

- composite nodes contribute internal actors and routes;
- edges contribute routes between public boundaries;
- every exposed, unfed node boundary whose input accepts `Unit` contributes one
  topology-derived `Unit` bootstrap message; incoming routes and explicit input
  messages suppress it, while nested actors stay dependency-driven;
- resident rules contribute typed subscriptions and function names; and
- the output node contributes the result boundary.

The resulting `Modification` value contains the operations understood by the
actor runtime. MAG serializes that value directly; the Nefor plugin owns its
schema and validation. Dynamic `Delta` values do not retain exposed node
boundaries, so their compatibility behavior is intentionally narrower: only an
unfed exact-`Unit` actor input is bootstrapped. Feed other delta actors
explicitly rather than assuming completed-graph root activation applies.

## Execution

The runtime registers the constellation, delivers initial messages, invokes
capabilities, and routes outputs according to typed firing rules. Facts that
exist only during execution—provider responses, process termination, human
decisions, tool results—remain runtime results and can feed later checked graph
transitions.

The runtime plugin documents the
[`IR`](../../../plugins/mag/docs/ir.md),
[`lowering`](../../../plugins/mag/docs/lowering.md), and
[`actor model`](../../../plugins/mag/docs/actor-model.md) in detail.
