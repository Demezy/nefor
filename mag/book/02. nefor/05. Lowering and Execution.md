# Lowering and Execution

As MAG compiles an artifact, Nefor's graph libraries perform domain validation
before the actor runtime receives application data.

## Validation moves failures left

Node identity, typed boundaries, source/output shape, product coverage, runtime
contracts, reachability, and operation trigger outputs are checked during
construction and lowering. Typed captures and expression constructors retain
semantic descriptors while the closed operation schema prevents arbitrary code
from entering the artifact.

The implementation is in
[`nefor/graph.mag`](../../lib/nefor/graph.mag),
[`nefor/mag.mag`](../../lib/nefor/mag.mag), and
[`nefor/artifact.mag`](../../lib/nefor/artifact.mag).

## Lowering

Applying `compile` expands graph values:

- composite nodes contribute internal actors and routes;
- edges contribute routes between public boundaries;
- every exposed, unfed node boundary whose input accepts `Unit` contributes one
  topology-derived `Unit` bootstrap message; incoming routes and explicit input
  messages suppress it, while nested actors stay dependency-driven;
- ordered `InstantiateDeltaTemplate` operations contribute typed triggers,
  captures, the five expression forms, and structural templates; and
- the output node contributes the result boundary.

Nefor emits an explicit `{format: "nefor.mag", version: 1}` envelope. Program
envelopes contain an initial concrete modification plus ordered operations;
delta envelopes contain one concrete delta and no result or nested operations.
Core MAG serializes this application value without knowing its schema.

A version-1 template has actor slots, local and existing actor references,
typed routes and product positions, typed messages, logical paths, scalar
parameter bindings, and explicit `actor_id`/`actor_id_list` relocation
metadata. Its expression vocabulary is exactly `Trigger`, `Capture`, `Field`,
`IntToDecimalString`, and `ConcatStrings`. It has no source, bytecode, generic
AST, condition, cache directive, evaluator, post-compilation function call, or
generic construction expression.

Dynamic `Delta` values do not retain exposed node
boundaries, so their compatibility behavior is intentionally narrower: only an
unfed exact-`Unit` actor input is bootstrapped. Feed other delta actors
explicitly rather than assuming completed-graph root activation applies.

## Execution

`mag.load` compiles and preflights an immutable program or delta envelope. It
returns the exact envelope and its content hash; it retains no compiler state.
`mag.execute` accepts only a program envelope and starts a fresh run.
`mag.apply` accepts only a delta envelope and atomically changes one live run.
Raw unversioned payloads and crossed envelope kinds are rejected.

The runtime preflights the complete operation list, registers the initial
constellation, delivers initial messages, invokes capabilities, and routes
outputs according to typed firing contracts. A matching output queues its
`InstantiateDeltaTemplate` operation. The kernel evaluates the closed
expression tree against that output, relocates the structural template,
validates the resulting delta against the live inventory, and applies it
atomically. Nested matching emissions join the same FIFO operation queue;
terminal success waits for that queue to become quiescent.

Version 2 deliberately provides no artifact cache, general runtime expression
language, or function application after compilation.

The runtime plugin documents the
[`IR`](../../../plugins/mag/docs/ir.md),
[`lowering`](../../../plugins/mag/docs/lowering.md), and
[`actor model`](../../../plugins/mag/docs/actor-model.md) in detail.
